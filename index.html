How I run it

Structure

Winners get budget in steps and roll out to more venues. Losers get switched off early, before they burn the week’s spend.

Inside the engine

The missing purchases.

The problem

Bookings were happening, but none of them showed up as purchases. A third-party booking widget ran inside an iframe, so Meta and GA4 never saw the sale. Campaigns were being judged on clicks.

What I did

Rebuilt the journey around a custom confirmation page, then wired Meta Pixel, server-side Conversions API and GA4 ecommerce events to it. Consolidated 41 pixels down to one per venue.

The result

Revenue became visible for the first time, ROAS improved 2.43x, and budget decisions now rest on real sales.
